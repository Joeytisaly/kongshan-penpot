# 空山 · 设计规范

## 1. 品牌

- **名称**：空山（出自王维《鹿柴》：「空山不见人，但闻人语响」——匿名社区里看不见人，只听见心事）
- **Logo**：森林绿圆 + 深色洞口（圆中洞，即「树洞」），配书法体「空山」二字
- **气质**：深夜、森林、灯火；温柔克制，不喧哗

### 字体

- 正文/UI：**系统字体栈**（PingFang SC / Microsoft YaHei 等，大陆必达）
- 品牌/标题：**Ma Shan Zheng**（书法体，仅 Logo、版块名、等级名）——**自托管 woff2 子集**（`assets/fonts/ma-shan-zheng-subset.woff2`，299KB，仅含项目文案用字；不依赖 Google Fonts，大陆可达）。新增文案需重新子集化（fonttools 脚本见 S24）。书法体只用于**大字号品牌位**（Logo 26px、版块页标题、等级名大字）；小字号辅助信息（如楼层作者栏的等级标签 11px）用系统字体栈保证可读性（P17-5 口径细化）
- 字号阶梯：11（辅助）/ 12（次级）/ 13（列表）/ 14（正文）/ 15（卡片标题）/ 20（页标题）/ 26（品牌）
- 输入控件（P15-2）：内容输入一律 14px（fs-body）+ 主文字色 var(--text)（placeholder 用次级灰）——输入可用性优先于列表字号阶梯；聚焦态白底 + 主色边框（纯 CSS :focus）；回复框 4 行起可拖拽增高
- 圆角：卡片 12–16px，按钮/标签 全圆角（高度一半），输入框 8px
- 阴影：`0 2px 10px rgba(38,51,44,0.07)`（仅主卡片与主按钮）

## 5. 文案语气

- 温柔、简短、第二人称；示例：「说出来吧，树洞在听。」「没有更多消息了。」
- 安全提示不吓人：「如果你正在经历特别难的时刻，请记住：心理援助热线 12356 一直在。」
- 空状态示例：「这里还很安静，做第一个说话的人吧。」

## 6. 移动端降级规范（P6）

设计稿为 1440×1024 桌面基准：**≥1081px 视口严格还原画板**，不因适配改动桌面视觉。窄视口按以下三档降级（纯 CSS 媒体查询实现，DOM/组件不变）：

| 断点 | 降级规则 |
|---|---|
| ≤1080px | 顶栏收窄（padding 24px）；搜索框弹性收缩（`flex:1`）；顶栏用户编号隐藏 |
| ≤880px | home / board / thread / me / mod 网格全部降**单栏**，侧栏卡片按 `order` 移到主内容下方；导航条横向滑动（不换行不折叠）；主容器左右 16px |
| ≤560px（手机） | 帖子列表行改**两行式**（标题整行 + 作者·回复/查看·时间第二行，列表表头隐藏）；楼层作者栏收窄至 64px；卡片 padding 收紧 14/16px；分页与个人统计换行；站务行纵向堆叠 |

原则：
1. 信息优先级：主内容 > 身份/统计 > 导航
2. 「我的树洞 / 消息」入口任何断点下不隐藏
3. 不为手机硬造数据（宁缺毋假）
4. 桌面画板还原始终以本文件 §3 为准，媒体查询只允许在窄断点内生效
5. 移动断点（≤560px）输入控件字号一律 16px——iOS Safari 对更小字号的输入框聚焦时强制放大整页（P12-4）；桌面保持字号阶梯不变
